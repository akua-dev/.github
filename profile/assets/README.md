# Profile assets

`akua-github-profile-banner.svg` is the source of `akua-github-profile-banner.png`
(1167x690). The headline and subline are Geist converted to paths and the logo is
the official Akua logo with its wordmark filled for the dark background, so the SVG
renders identically without any installed font. Edit the SVG, then render it to a 1167x690 PNG with any librsvg or resvg based
renderer (the committed PNG was rendered with sharp at 144 dpi).
